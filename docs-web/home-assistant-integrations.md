# Home Assistant Integrations

This document lists the integrations currently installed in this Home Assistant instance.

## Core Integrations

*   **Sun:** Provides sun-based triggers and conditions.
*   **go2rtc:** A real-time media server for cameras and other media sources.
*   **Backup:** Manages Home Assistant backups.
*   **Thread:** Enables Thread network support.
*   **Shopping List:** A simple shopping list integration.
*   **Google Translate:** Text-to-speech service using Google Translate.
*   **Met:** Weather forecasts from the Norwegian Meteorological Institute.
*   **HACS:** Home Assistant Community Store for custom integrations.
*   **Android TV Remote:** Control Android TV devices.
*   **Telegram Bot:** Send and receive messages via Telegram.
*   **FordPass:** Integration for FordPass connected vehicles.
*   **Google Generative AI Conversation:** Integration with Google's generative AI models.
*   **Google Calendar:** Sync with Google Calendar.
*   **Bluetooth:** Enables Bluetooth support.
*   **MJPEG:** IP camera support.
*   **Media Extractor:** Extracts media from URLs.
*   **HomeKit Controller:** Control HomeKit devices.
*   **Environment Canada:** Weather forecasts from Environment Canada.
*   **Local To-Do:** A local to-do list.
*   **Mobile App:** Integration with the Home Assistant mobile app.
*   **MQTT:** Connect to an MQTT broker.
*   **Wyoming:** Protocol for voice assistants.
*   **Google Cast:** Control Google Cast devices.
*   **ESPHome:** Manage ESPHome devices.
*   **Ollama:** Integration with the Ollama local AI model server.
*   **Browser Mod:** Control web browsers as media players.
*   **Roku:** Control Roku devices.
*   **Plex Media Server:** Integration with Plex.
*   **TP-Link:** Control TP-Link smart devices.
*   **Portainer:** Monitor and manage Docker containers.
*   **qBittorrent:** Manage qBittorrent downloads.
